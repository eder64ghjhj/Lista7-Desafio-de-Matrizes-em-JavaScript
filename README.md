# 🔢 Lista 7 — Desafio de Matrizes em JavaScript

Série de exercícios com matrizes (arrays bidimensionais) em JavaScript, explorando declaração, percurso e operações sobre estruturas de dados multidimensionais.

## 📚 Conteúdo

- Declaração e inicialização de matrizes
- Percurso com laços aninhados
- Operações sobre linhas e colunas
- Busca e manipulação de elementos em matrizes
- Desafios de lógica com estruturas bidimensionais

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
